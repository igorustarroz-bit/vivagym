# VivaGym · Prototipo (Hanzo)

Prototipo navegable en código del flujo de VivaGym Puerta del Sol (ficha de gimnasio + alta en 4 pasos), con estética wireframe.

- Pensado para móvil (320–440 px). En escritorio se muestra como una columna de móvil centrada.
- Un único `index.html` autocontenido; se publica con GitHub Pages desde la rama `main` (raíz).
- Rutas por hash: `#inicio`, `#extras`, `#contacto`, `#datos`, `#pago`, `#visita`, `#confirmacion`.
